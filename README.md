# 📊 E-Commerce Sales Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing an **E-Commerce Sales Dataset** using **Microsoft Excel** as part of my Data Analytics learning journey.

The project demonstrates the complete data analytics workflow, starting from **data import and cleaning** to **data transformation, statistical analysis, visualization, and dashboard creation**.

The objective is to transform raw e-commerce data into meaningful insights that can support better understanding of **sales performance, customer behavior, product performance, and business trends**.

---

## 🎯 Project Objectives

* Import and organize an e-commerce dataset in Excel
* Clean and prepare the dataset for analysis
* Identify and remove duplicate records
* Handle missing and inconsistent data
* Correct formatting and data quality issues
* Remove irrelevant columns where applicable
* Apply Excel formulas for calculations and analysis
* Combine related tables using **VLOOKUP/XLOOKUP**
* Create Pivot Tables for data summarization
* Calculate descriptive statistics
* Create charts and PivotCharts
* Build an interactive Excel dashboard
* Extract meaningful business insights from the dataset

## 4️⃣ XLOOKUP / VLOOKUP

**XLOOKUP/VLOOKUP** functions were used to combine information from different tables.

This helped create a more complete analytical dataset by retrieving related information from dimension or reference tables.

### Example

```excel
=XLOOKUP(A2,Product_Dim[Product_ID],Product_Dim[Product_Name])
```

or

```excel
=VLOOKUP(A2,Product_Dim,2,FALSE)
```

### Purpose

* Combine related tables
* Retrieve missing attributes
* Connect fact and dimension data
* Prepare data for Pivot Table analysis
